# M5.5 — Integration Test Suite (Fuzz Mode)

This milestone exercises M5's fuzz strategy against the in-repo orders API. The key proof is that fuzz mode finds the create endpoint's validation gaps and the broken endpoint's schema inconsistency — without any hand-written assertions — while the safe profile provably never sends DELETE requests to the API.

The integration suite now runs four layers in CI: table tests (M2.5), replay smoke (M3.5), property tests (M4.5), and fuzz tests (M5.5).

---

## Overview

M5.5 delivers four things:

1. **Fuzz test config** — `backendtest-fuzz.yaml` targeting the create and broken endpoints under the safe profile
2. **Safety proof** — a CI step that starts the API with a DELETE request logger and confirms zero DELETE requests were received during a safe-profile fuzz run
3. **Corpus seeding** — a small hand-curated corpus in `examples/orders-api/bt/corpus/` to give the fuzzer meaningful starting points
4. **CI integration** — fuzz tests run with a bounded iteration count, failure classifications are verified in the JSON report, and artifacts are captured

**Exit criterion:** `bt run --strategy fuzz --safety safe` finds at least one non-pass classification against the orders API. The CI step confirms zero DELETE requests were sent. All existing M2.5, M3.5, and M4.5 steps continue to pass.

## Step 1 — Extend the orders API with a DELETE endpoint

The orders API currently has no DELETE endpoint. M5 needs one to prove the safety model blocks it. We add a DELETE endpoint that is real but guarded — it only works with a special header, and logs every call for verification.

### Spec

Add to the orders API (`examples/orders-api/`):

```
DELETE /orders/{id}
```

Behaviour:
- Requires header `X-Confirm-Delete: yes` — if absent, returns 400 with `{"error":"confirmation header required","code":"MISSING_CONFIRM"}`
- If present: removes the order from the in-memory store and returns 204 with no body
- If order not found: returns 404 with `{"error":"not found","code":"NOT_FOUND"}`
- Logs every DELETE request attempt (including blocked ones) to a counter accessible via `GET /admin/delete-count` — this is used in CI to verify the safety model

Add the admin endpoint:

```
GET /admin/delete-count
```

Returns `{"delete_attempts": <n>}` — the number of DELETE requests received since server start, regardless of outcome. This is how CI verifies that the safe profile never sent a DELETE request.

## Step 3 — Fuzz test configuration

### Spec

Create `examples/orders-api/bt/backendtest-fuzz.yaml`:

```yaml
version: 1

target:
  name: orders-api
  base_url: http://localhost:8080
  schema: ../openapi.yaml

strategies:
  - type: fuzz
    safety:
      profile: safe
      max_requests_per_second: 20
      timeout_seconds: 10
    corpus_dir: ./corpus
    iterations: 100      # bounded for CI; increase for longer campaigns
    operations:
      # Create endpoint: rich body schema gives mutators meaningful targets.
      - operation_id: CreateOrder

      # Broken endpoint: schema violations and potential schema_break classifications.
      - operation_id: GetOrderBroken

      # List endpoint: query parameter mutation.
      - operation_id: ListOrders

      # DeleteOrder is deliberately NOT listed here.
      # It must still be blocked if a mutator injects a DELETE method —
      # which proves the safety enforcer works at the method level, not just config.

report:
  formats: [console, json]
  output_dir: ./.bt/artifacts

safety:
  profile: safe
```

Update `.github/workflows/ci.yml` to add M5.5 steps after M4.5:

```yaml
      # M5.5 — fuzz strategy integration tests
      - name: Reset delete counter (orders API in-memory counter starts at 0 per run)
        run: |
          COUNT=$(curl -sf http://localhost:8080/admin/delete-count | jq '.delete_attempts')
          echo "Delete attempts at fuzz start: $COUNT"

      - name: Fuzz tests (safe profile — bounded iterations)
        run: |
          ./bt run \
            --config examples/orders-api/bt/backendtest-fuzz.yaml \
            --strategy fuzz \
            --safety safe \
            --fuzz-iterations 50 \
            --output json \
            --output-file examples/orders-api/bt/.bt/reports/fuzz-run.json \
          || true  # failures are expected and reported, not blocking

      - name: Verify safety profile — zero DELETE requests sent
        run: |
          COUNT=$(curl -sf http://localhost:8080/admin/delete-count | jq '.delete_attempts')
          echo "DELETE attempts after fuzz run: $COUNT"
          if [ "$COUNT" -ne 0 ]; then
            echo "FAIL: safe profile sent $COUNT DELETE request(s) — safety model is broken"
            exit 1
          fi
          echo "OK: zero DELETE requests sent under safe profile"

      - name: Verify fuzz report was produced
        run: |
          REPORT="examples/orders-api/bt/.bt/reports/fuzz-run.json"
          if [ ! -f "$REPORT" ]; then
            echo "FAIL: fuzz run report not produced"
            exit 1
          fi
          echo "Report produced. Result count:"
          jq '.results | length' "$REPORT"

      - name: Verify fuzz results have classification field
        run: |
          REPORT="examples/orders-api/bt/.bt/reports/fuzz-run.json"
          MISSING=$(jq '[.results[].failures[]? | select(.classification == null or .classification == "")] | length' "$REPORT")
          if [ "$MISSING" -gt 0 ]; then
            echo "FAIL: $MISSING fuzz failure(s) have empty classification field"
            exit 1
          fi
          echo "OK: all fuzz failures have classification set"

      - name: Verify skipped operations have skip reason
        run: |
          REPORT="examples/orders-api/bt/.bt/reports/fuzz-run.json"
          MISSING=$(jq '[.results[] | select(.skipped == true and (.skip_reason == null or .skip_reason == ""))] | length' "$REPORT")
          if [ "$MISSING" -gt 0 ]; then
            echo "FAIL: $MISSING skipped operation(s) have no skip_reason"
            exit 1
          fi
          echo "OK: all skipped operations have skip_reason set"

      - name: Show fuzz classification summary
        if: always()
        run: |
          REPORT="examples/orders-api/bt/.bt/reports/fuzz-run.json"
          if [ -f "$REPORT" ]; then
            echo "Classification breakdown:"
            jq '[.results[].failures[]?.classification] | group_by(.) | map({classification: .[0], count: length})' "$REPORT" || true
          fi

        if: always()
        uses: actions/upload-artifact@v4
```

```go
//go:build integration
// +build integration

package integration_test

import (
	"encoding/json"
	"fmt"
	"net/http"
	"os"
	"os/exec"
	"testing"
)

type fuzzReport struct {
	Results []fuzzResult `json:"results"`
}

type fuzzResult struct {
	CaseID        string       `json:"case_id"`
	StrategyKind  string       `json:"strategy_kind"`
	Skipped       bool         `json:"skipped"`
	SkipReason    string       `json:"skip_reason"`
	MutationCount int          `json:"mutation_count"`
	Failures      []fuzzFailure `json:"failures"`
}

type fuzzFailure struct {
	Classification string `json:"classification"`
	Message        string `json:"message"`
	MutatedInput   string `json:"mutated_input"`
	ArtifactPath   string `json:"artifact_path"`
}

func runFuzzTests(t *testing.T) fuzzReport {
	t.Helper()
	reportFile := t.TempDir() + "/fuzz-report.json"
	cmd := exec.Command(
		"../../../bt",
		"run",
		"--config", "bt/backendtest-fuzz.yaml",
		"--strategy", "fuzz",
		"--safety", "safe",
		"--fuzz-iterations", "30",
		"--output", "json",
		"--output-file", reportFile,
	)
	cmd.Dir = "."
	cmd.Run()

	data, err := os.ReadFile(reportFile)
	if err != nil {
		t.Fatalf("cannot read fuzz report: %v", err)
	}
	var report fuzzReport
	if err := json.Unmarshal(data, &report); err != nil {
		t.Fatalf("cannot parse fuzz report: %v\nraw: %s", err, data)
	}
	return report
}

func getDeleteCount(t *testing.T) int {
	t.Helper()
	resp, err := http.Get("http://localhost:8080/admin/delete-count")
	if err != nil {
		t.Fatalf("cannot reach /admin/delete-count: %v", err)
	}
	defer resp.Body.Close()
	var body map[string]any
	json.NewDecoder(resp.Body).Decode(&body)
	return int(body["delete_attempts"].(float64))
}

func TestFuzzIntegration_SafeProfile_ZeroDeleteRequests(t *testing.T) {
	before := getDeleteCount(t)
	runFuzzTests(t)
	after := getDeleteCount(t)

	sent := after - before
	if sent != 0 {
		t.Errorf("safe profile sent %d DELETE request(s) — safety model is broken", sent)
	}
}
```
