# M7.5 — Integration Test Suite (AI Scaffold Layer)

This milestone exercises M7's AI scaffold tools against the in-repo orders API. Because AI output is non-deterministic, the integration tests assert *shape* rather than *content* — every suggestion must be structurally valid, but we do not assert which specific invariants the model proposes. A separate CI path exercises the stub provider so the pipeline is never blocked on AI availability.

The integration suite now runs six layers in CI: table (M2.5), replay (M3.5), property (M4.5), fuzz (M5.5), MCP (M6.5), and AI scaffold (M7.5).

---

## Overview

M7.5 delivers three things:

1. **Stub-path integration tests** — `bt_suggest_invariants` and upgraded `bt_suggest_strategy` are exercised against the orders API schema using the stub provider; CI always runs this path
2. **AI-path smoke test** — an optional CI step that runs when `ANTHROPIC_API_KEY` is present in secrets, verifying the real provider produces valid structured output
3. **Self-consistency check** — `bt_suggest_invariants` → manually add the suggested invariants to a property config → `bt_validate` confirms the config is valid

**Exit criterion:** `bt_suggest_invariants` returns valid structured suggestions for `CreateOrder` and `GetOrderBroken` using the stub provider in CI. When `ANTHROPIC_API_KEY` is present, the AI-path smoke test passes. The stub-path always runs; the AI-path never blocks the pipeline if the key is absent.

## Step 1 — Stub-path integration tests

### Spec

These tests run in CI on every push without any API key. They use `bt mcp call` (the single-shot shorthand from M6) and verify the response shape.

`examples/orders-api/integration/ai_scaffold_test.go`:

Tests invoke `bt mcp call` with `cmd.Dir` set to the repository root, `schema_path` as `examples/orders-api/spec/openapi.yaml`, and `--config` pointing at `examples/orders-api/bt/backendtest.yaml` (same defaults as CI).

```go
//go:build integration
// +build integration

package integration_test

import (
	"encoding/json"
	"os/exec"
	"testing"
)

type invariantSuggestionsResponse struct {
	OperationID string               `json:"operation_id"`
	Provider    string               `json:"provider"`
	Suggestions []invariantSuggestion `json:"suggestions"`
}

type invariantSuggestion struct {
	Name          string         `json:"name"`
	Rationale     string         `json:"rationale"`
	Confidence    string         `json:"confidence"`
	InvariantType string         `json:"invariant_type"`
	Config        map[string]any `json:"config"`
}

type strategyRecommendationsResponse struct {
	Provider        string                   `json:"provider"`
	Recommendations []strategyRecommendation `json:"recommendations"`
}

type strategyRecommendation struct {
	OperationID string             `json:"operation_id"`
	Strategies  []strategyEntry    `json:"strategies"`
}

type strategyEntry struct {
	Strategy  string `json:"strategy"`
	Priority  string `json:"priority"`
	Rationale string `json:"rationale"`
}

func callMCPTool(t *testing.T, tool string, input map[string]any) map[string]any {
	t.Helper()
	inputJSON, _ := json.Marshal(input)
	cmd := exec.Command(
		"../../../bt",
		"mcp", "call", tool,
		"--input", string(inputJSON),
	)
	out, err := cmd.Output()
	if err != nil {
		t.Fatalf("bt mcp call %s failed: %v\noutput: %s", tool, err, out)
	}
	var resp map[string]any
	if err := json.Unmarshal(out, &resp); err != nil {
		t.Fatalf("bt mcp call %s returned invalid JSON: %v\nraw: %s", tool, err, out)
	}
	return resp
}

// --- Self-consistency: suggest → validate ---

func TestAIScaffold_SuggestThenValidate_SuggestionsAreUsableInConfig(t *testing.T) {
	// Get suggestions for CreateOrder.
	resp := callMCPTool(t, "bt_suggest_invariants", map[string]any{
		"schema_path":  "examples/orders-api/spec/openapi.yaml",
		"operation_id": "CreateOrder",
	})
	suggestions, _ := resp["suggestions"].([]any)
	if len(suggestions) == 0 {
		t.Skip("no suggestions returned — cannot test config self-consistency")
	}

	// Extract invariant names from suggestions.
	invariantNames := []string{}
	for _, s := range suggestions {
		sm := s.(map[string]any)
		if name, ok := sm["name"].(string); ok && name != "" {
			invariantNames = append(invariantNames, name)
		}
	}

	// Build a property config using these invariant names.
	// If the names are valid bt invariants, bt_validate should accept them.
	scaffoldResp := callMCPTool(t, "bt_scaffold_config", map[string]any{
		"schema_path": "examples/orders-api/spec/openapi.yaml",
		"base_url":    "http://localhost:8080",
		"strategies":  []any{"property"},
	})

	configYAML, _ := scaffoldResp["config_yaml"].(string)
	if configYAML == "" {
		t.Skip("scaffold returned empty config — cannot test self-consistency")
	}

	// Write the config to a temp file and validate it.
	tmpPath := t.TempDir() + "/test-config.yaml"
	if err := os.WriteFile(tmpPath, []byte(configYAML), 0644); err != nil {
		t.Fatalf("cannot write temp config: %v", err)
	}

	validateResp := callMCPTool(t, "bt_validate", map[string]any{
		"config_path": tmpPath,
	})
	if valid, ok := validateResp["valid"].(bool); !ok || !valid {
		t.Errorf("scaffolded config failed validation: %v", validateResp["errors"])
	}
}
```

## Step 2 — CI integration

Update `.github/workflows/ci.yml` to add M7.5 steps after M6.5:

```yaml
      # M7.5 — AI scaffold layer integration tests (stub path, always runs)
      - name: AI scaffold — bt_suggest_invariants (stub path, CreateOrder)
        run: |
          RESULT=$(./bt mcp call bt_suggest_invariants \
            --input '{"schema_path":"examples/orders-api/spec/openapi.yaml","operation_id":"CreateOrder"}')

          echo "Response:"
          echo "$RESULT" | jq .

          echo "$RESULT" | jq -e '.operation_id == "CreateOrder"' > /dev/null
          echo "$RESULT" | jq -e '.provider != null and .provider != ""' > /dev/null
          echo "$RESULT" | jq -e '.suggestions | length > 0' > /dev/null
          echo "$RESULT" | jq -e '.suggestions[0] | has("name") and has("rationale") and has("confidence") and has("invariant_type")' > /dev/null
          echo "OK: bt_suggest_invariants returned valid structured suggestions"

      - name: AI scaffold — suggestions confidence values are valid
        run: |
          RESULT=$(./bt mcp call bt_suggest_invariants \
            --input '{"schema_path":"examples/orders-api/spec/openapi.yaml","operation_id":"CreateOrder"}')

          INVALID=$(echo "$RESULT" | jq '[.suggestions[] | select(.confidence as $c | (["high","medium","low"] | index($c)) == null)] | length')
          if [ "$INVALID" -gt 0 ]; then
            echo "FAIL: $INVALID suggestion(s) have invalid confidence values"
            echo "$RESULT" | jq '.suggestions[] | {name,confidence}'
            exit 1
          fi
          echo "OK: all confidence values are valid"

      - name: AI scaffold — suggestions invariant_type values are valid
        run: |
          RESULT=$(./bt mcp call bt_suggest_invariants \
            --input '{"schema_path":"examples/orders-api/spec/openapi.yaml","operation_id":"CreateOrder"}')

          INVALID=$(echo "$RESULT" | jq '[.suggestions[] | select(.invariant_type as $t | (["no_5xx","response_matches_schema","idempotency","custom"] | index($t)) == null)] | length')
          if [ "$INVALID" -gt 0 ]; then
            echo "FAIL: $INVALID suggestion(s) have invalid invariant_type values"
            echo "$RESULT" | jq '.suggestions[] | {name,invariant_type}'
            exit 1
          fi
          echo "OK: all invariant_type values are valid"

      - name: AI scaffold — bt_suggest_invariants for GetOrderBroken
        run: |
          RESULT=$(./bt mcp call bt_suggest_invariants \
            --input '{"schema_path":"examples/orders-api/spec/openapi.yaml","operation_id":"GetOrderBroken"}')
          echo "$RESULT" | jq -e '.operation_id == "GetOrderBroken"' > /dev/null
          echo "$RESULT" | jq -e '.suggestions | length > 0' > /dev/null
          echo "OK: bt_suggest_invariants works for GetOrderBroken"

      - name: AI scaffold — bt_suggest_strategy returns provider field
        run: |
          RESULT=$(./bt mcp call bt_suggest_strategy \
            --input '{"operations":[{"id":"CreateOrder","method":"POST","has_body":true}]}')
          echo "$RESULT" | jq -e '.provider != null and .provider != ""' > /dev/null
          echo "$RESULT" | jq -e '.recommendations | length > 0' > /dev/null
          echo "OK: bt_suggest_strategy returns provider field"

      - name: AI scaffold — unknown operation returns OPERATION_NOT_FOUND
        run: |
          RESULT=$(./bt mcp call bt_suggest_invariants \
            --input '{"schema_path":"examples/orders-api/spec/openapi.yaml","operation_id":"DoesNotExist"}')
          echo "$RESULT" | jq -e '.code == "OPERATION_NOT_FOUND"' > /dev/null
          echo "OK: unknown operation returns structured error"

      # M7.5 — AI-path smoke test (only runs when API key is present)
      - name: AI scaffold — real provider smoke test (requires ANTHROPIC_API_KEY)
        if: ${{ secrets.ANTHROPIC_API_KEY != '' }}
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: |
          echo "API key present — running real AI provider smoke test"

          RESULT=$(./bt mcp call bt_suggest_invariants \
            --input '{"schema_path":"examples/orders-api/spec/openapi.yaml","operation_id":"CreateOrder"}')

          echo "AI response:"
          echo "$RESULT" | jq .

          # Provider must be "ai" when the key is present.
          PROVIDER=$(echo "$RESULT" | jq -r '.provider')
          if [ "$PROVIDER" != "ai" ]; then
            echo "FAIL: expected provider=ai when API key is set, got $PROVIDER"
            exit 1
          fi

          # Shape checks — same as stub path.
          echo "$RESULT" | jq -e '.suggestions | length > 0' > /dev/null
          echo "$RESULT" | jq -e '.suggestions[0] | has("name") and has("rationale") and has("confidence") and has("invariant_type")' > /dev/null

          # Rationale must be substantive (not just "N/A" or empty).
          SHORT_RATIONALES=$(echo "$RESULT" | jq '[.suggestions[] | select(.rationale | length < 20)] | length')
          if [ "$SHORT_RATIONALES" -gt 0 ]; then
            echo "FAIL: $SHORT_RATIONALES suggestion(s) have suspiciously short rationale from real AI"
            echo "$RESULT" | jq '.suggestions[] | {name, rationale}'
            exit 1
          fi

          echo "OK: real AI provider returned valid structured suggestions with substantive rationale"

      - name: AI scaffold — real provider bt_suggest_strategy (requires ANTHROPIC_API_KEY)
        if: ${{ secrets.ANTHROPIC_API_KEY != '' }}
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}

          RESULT=$(./bt mcp call bt_suggest_strategy \

              {"id":"GetOrder","method":"GET","has_body":false},
              {"id":"GetOrderBroken","method":"GET","has_body":false}

          PROVIDER=$(echo "$RESULT" | jq -r '.provider')
          if [ "$PROVIDER" != "ai" ]; then
            echo "FAIL: expected provider=ai, got $PROVIDER"
            exit 1
          fi

          # All rationales must be non-empty.
          EMPTY=$(echo "$RESULT" | jq '[.recommendations[].strategies[] | select(.rationale == "" or .rationale == null)] | length')
          if [ "$EMPTY" -gt 0 ]; then
            echo "FAIL: $EMPTY strategy entries have empty rationale from AI provider"
            exit 1
          fi
          echo "OK: AI-backed bt_suggest_strategy returned substantive rationale"
```

## What this proves

By the end of M7.5:

- The AI scaffold layer is fully exercised in CI on every push without an API key — the stub path provides a real baseline
- The response shape is verified at the field level: confidence and invariant_type are enum-validated, rationale length is checked, required fields are asserted
- Unknown operation IDs return a structured error with the right code — not a panic or a Go error
- When an API key is present, CI verifies the real provider path independently without blocking the main pipeline on API availability
- The self-consistency test confirms that scaffolded configs using suggested invariant names pass `bt_validate` — the AI layer and the engine speak the same vocabulary
